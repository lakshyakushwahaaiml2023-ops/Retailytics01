## Key Features
- Next.js app with onboarding page for business registration
- API route for creating businesses in the database
- Prisma ORM with SQLite
- Models: User, Business, Product, Order, OrderItem
- Tailwind CSS for styling

---

## Example: Onboarding Page (app/onboarding/page.tsx)
- Collects: name, type, city, locality, areaType, customerAgeRange, deliveryRadius
- Validates all fields
- Submits to /api/business (POST)

## Example: API Route (app/api/business/route.ts)
- Receives POST request
- Creates business in database using Prisma

## Example: Prisma Schema (prisma/schema.prisma)
- User, Business, Product, Order, OrderItem models with relations

## How to Continue
- Install dependencies: npm install
- Run dev server: npm run dev
- Migrate DB: npx prisma migrate dev
- Edit onboarding form or add new features as needed
